# Kun v0.2.36

v0.2.36 重点提升 Agent Graph、运行时恢复和模型连接的稳定性，同时加入探索型子代理、会话级后台任务和更完整的设计工作流。升级路径、Provider 配置和跨平台运行时也得到进一步加固。

### Agent Graph 与子代理

- 新增 `explore_agent` 工具，支持带上下文的探索任务、Lab 配置和 Codex 快速执行路径，便于把研究、分析和验证拆分给专门的子代理。
- 改进 Graph 的控制、监督、交接、结果评审和恢复流程；在子代理已经持久化但通知并发冲突时，结果会继续保持可评审状态，不会被误判为不可恢复失败。
- 工具调用风暴保护改为可配置策略，并完善普通工具失败、模型中断和多轮恢复时的状态收敛。
- 增加持久化压缩记录、模型历史修复、重试预算和流式请求恢复，减少长会话中断后出现重复、丢失或无法继续的问题。

### 运行时、迁移与数据安全

- 加固 Kun runtime 生命周期、服务管理、审批租约和设置变更序列化，降低重启、并发设置保存和运行中切换造成的状态冲突。
- 新增运行时数据目录的锁、迁移和恢复机制；迁移被中断或启动失败时，应用会保留恢复信息并提供恢复界面，不会猜测性删除用户数据。
- 补齐跨版本运行时数据迁移 fixture，覆盖从 v0.2.29 到 v0.2.35 的升级路径。
- 卸载设置中显示实际安装路径，帮助用户确认正在移除的应用实例，避免多份安装并存时误操作。

### Provider、模型与外部服务

- 改进 OpenAI-compatible、Anthropic 和其他兼容模型请求的消息投影、流式解码、Endpoint format、模型切换、重试和请求追踪。
- Provider 凭据与设置更新改为 revision-safe，减少异步保存导致的配置回退；模型目录在 models.dev 不可用时可回退到 Kun 官方目录。
- 增强 OpenCode Go 的 Cookie 解析与订阅额度读取，并完善 Gemini、Cursor、图片生成和媒体生成 Provider 的运行时适配。
- 浏览器工具增加参数校验和恢复行为，减少外部页面状态变化导致的工具调用失败。

### 工作流与生产力

- 新增会话级 daemon 后台任务，支持日志查看、定时运行和微信推送；任务运行期间应用会正确处理休眠与电源状态。
- Design 工作流支持 HTML artifact 版本、组件原型导入画布、画布图层操作和版本隐藏状态持久化。
- 改进 SDD 子代理返回导航、Workbench 页面记忆、计划消息排队和运行时事件投影，减少切换页面或恢复会话时的上下文丢失。
- 设置页补充 Provider API key 占位符、卸载状态和模型目录回退提示，并继续完善多语言文案。

### CLI、TUI 与发布稳定性

- CLI 与 standalone TUI 共享更一致的 runtime、设置桥接和自更新行为，模型连接和运行时数据迁移逻辑保持一致。
- 加固 macOS、Windows、Linux、Extension、OCR、FFmpeg 和 TUI 的发布门禁，跨平台构建检查更严格地绑定最终制品与对应 commit。

### 升级说明

- 从 v0.2.35 升级无需手动迁移普通会话、工作区、Graph 或 Provider 配置。
- 如果升级过程中运行时数据迁移被中断，请按应用内恢复提示完成恢复或回滚；不要手动删除 Kun 数据目录。
- 使用会话级 daemon 或微信推送前，请在设置中确认对应凭据和推送配置已保存。
