# Kun v0.2.32

v0.2.32 带来了受监督的 Agent Graph 编排模式和完整的 Kun TUI。复杂任务现在可以拆成可验收的依赖图，由 Lead Agent 调度受限子代理、持续检查执行证据并统一交付；桌面端和终端端则共享同一个 Kun Runtime、会话、模型连接、审批和后台任务。与此同时，配额监控、模型请求重试、运行时迁移和工作台操作也得到进一步完善。

### Agent Graph：让复杂任务可分工、可监督

- 新增 `Direct | Graph` 回合模式。Graph Lead 会把复杂需求编译成经过校验的任务图，支持并行扇出、串行流水线、有限修复循环、状态机和混合编排。
- Graph 右侧面板展示运行状态、节点、attempt、子代理会话、检查结果和 Artifact；可以对运行中的任务进行 steer、暂停/恢复、取消、重试、复核、重新绑定和受限修改。
- 子代理只拥有父回合、Graph 策略、Agent profile 与节点范围的权限交集，不能递归创建 Graph、绕过 Lead 验收或直接扩大工作区权限。
- 调度器增加依赖校验、并发控制、失败分类、退避重试、监督唤醒、恢复和资源清理。只有真实持久化状态、检查结果和 Lead 复核都满足时，Graph 才会进入完成状态。
- 新增项目级 Agent profile、Skill / Graph Recipe 候选、证据和审计能力。自动学习默认受策略控制，候选升级仍需要证据和用户授权。

### Kun TUI 与共享 Runtime

- 安装桌面应用后可直接运行 `kun` 或 `kun tui`，在终端中创建、继续和搜索会话；独立 TUI 发行包也随同 GUI 版本构建。
- TUI 与 GUI 共享线程、turn、审批、结构化问答、子代理、用量、模型连接和后台任务。关闭其中一个客户端不会终止另一个客户端或正在运行的回合。
- 新增内联会话流、紧凑的工具和子代理展示、Thinking 折叠、实时阶段状态、断线重连和原生终端 scrollback 保留，适合在终端中持续工作。
- `/connect`、`/model`、`/sessions`、`/usage`、`/update` 等命令和模型选择页得到完善；模型连接、凭据和默认模型可以在 TUI 与 GUI 之间同步使用。
- 增加共享 Runtime 的状态、重启和停止管理，以及带 build ID 校验的实例发现，避免 GUI 与 TUI 各自启动相互冲突的 Runtime。

### Provider、模型与额度

- 右侧栏、系统托盘和 TUI 都可以查看支持 Provider 的订阅额度与用量；额度按 Provider 状态分组展示，订阅 allowance 和 OpenCode Go 本地用量的读取也更加准确。
- 新增 Ollama Cloud 订阅和 Volcano Ark 媒体套餐；模型连接 registry 支持多个账号、受保护的凭据来源和 OAuth 刷新。
- 补充 Gemini Code Assist 接入，改进 Antigravity 模型发现，并迁移 Grok 的媒体请求协议。
- 模型请求支持可配置的网络与流式传输重试，默认最多重试 5 次；中断的模型流可以恢复，重试期间取消请求也会及时停止。
- Provider 和模型的请求格式、推理参数、侧对话路由及计划生成模型选择更加一致，减少不同工作流之间的配置偏差。

### Agent 视角与排障

- Agent 视角采集默认开启，模型请求、响应、工具、用量和耗时记录按回合分组，并支持请求历史分页查看。
- 请求记录进入本机前会脱敏；采集内容仍可能包含提示词、代码和模型输出，可在设置中关闭采集，分享诊断信息前请先检查本地记录。
- 审批复核、运行时设置、Graph 委派诊断和子代理事件展示更加清晰，聊天时间线会保持真实发生顺序并正确归并折叠工作阶段。

### 工作台与日常操作

- 会话侧边栏支持嵌套目录，删除目录不会删除其中的会话；工作区控制、分支对话和右侧工作区面板的入口进一步统一。
- Composer 支持切换 Enter 与 Shift+Enter 的发送/换行行为；Write 选区 AI Composer、Plan 操作和 SDD 计划生成会正确使用当前工作区与模型。
- 修复历史附件预览、生成媒体在当前时间线中的显示、对话时间线排序、Design 原型渲染、会话恢复和文件夹重名等问题。
- 新增面向托管桌面浏览器的 Browser Use 通道；需要可见且已认证的桌面宿主时，Agent 才会执行浏览器交互，并对请求权限、响应大小和关联回合进行校验。

### 运行时、迁移与发布

- Kun Runtime 数据迁移到 canonical data directory 时会保留线程、事件、附件、凭据、索引和配置，并创建可恢复的备份；历史会话和移动过的线程索引恢复更加可靠。
- Linux 发布新增 `.deb` 安装包，并加强 sidecar 与发布构建校验。
- 独立 TUI、GUI 和 Kun Runtime 使用同一版本与 build ID，减少客户端与运行时版本不匹配导致的问题。

### 升级说明

- 从 `v0.2.31` 升级无需手动迁移工作区、会话或 Provider 设置。使用旧版 `~/.deepseekgui/kun` 的用户会在启动时自动迁移到 `~/.kun/data`；迁移前会创建备份，旧路径会保留兼容链接。迁移期间请不要同时运行旧版 Kun Runtime。
- Graph 是按回合选择的编排模式；简单问答和小范围修改继续使用 Direct。需要停用 Graph 时，可在 Kun Runtime 的 Graph 设置中关闭新 Graph 创建；已有数据不会因关闭而删除。
- Agent 视角默认保存脱敏后的请求和响应记录到本机。若不希望保存这些内容，请在设置中关闭 Agent 视角采集。
- 如果准备降级到尚不识别 Graph 的旧版本，请先停止或完成所有活动 GraphRun；旧版本不会继续维护运行中的 Graph。
