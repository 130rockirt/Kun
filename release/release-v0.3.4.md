# Kun v0.3.4

v0.3.4 是 Windows 稳定性热修复版本，建议所有使用 v0.3.3 的 Windows 用户尽快通过应用内更新（如已启用）或下载安装包升级。本次更新不迁移、不删除会话、设置或工作区数据。

### Windows 安装器进程检测修复（#1179）

- 修复升级或卸载前的进程检查把“无法检查进程”误报为“Kun 无法关闭”的问题。
- 安装器现在只会在已验证仍有 Kun 应用进程占用安装目录时，提示用户关闭 Kun 并重试。
- 进程枚举、权限或安全校验发生异常时，会显示独立的安装检查失败提示并保留诊断信息；不会再把它伪装成应用仍在运行。
- 自动更新仍保持失败保护：无法安全确认安装目录未被占用时，更新会停止而不会覆盖可能正在使用的文件。

### Windows Runtime 与 Service Manager 重启恢复（#1180）

- 修复正常退出 Kun 后再次启动时，陈旧 Runtime 注册可能导致 `active_writer: production Runtime could not be inspected` 并阻止启动的问题。
- 普通关闭 GUI 后，共享 Kun Runtime 仍可按设计供其他客户端使用；新的 GUI 启动会通过 Service Manager 安全接管或复用健康 Runtime，而不是先强制终止它。
- 已退出 Runtime 留下的 Manager 注册会被自动识别并清理，随后启动可正常继续。
- 对仍存活但无法验证身份或响应的进程继续采取安全失败策略，避免误终止其他用户、客户端或数据目录所有者。

### 热修复升级说明

- 能正常打开 Kun 时，可在启用自动更新后安装此热修复；若当前无法启动，请下载 v0.3.4 Windows 安装包覆盖安装。
- 如果旧版本已经卡在启动错误页，先在任务管理器结束所有名称为 Kun 的进程后再启动或安装；不要结束其他 Node、Electron 或 MCP 进程。
- 强制结束 Kun 会中断正在执行的回复或任务，但不会删除已保存的会话数据。
