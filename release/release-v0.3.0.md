# Kun v0.3.0

v0.3.0 是一次较大的功能版本：Code / Design / Work 统一进同一个工作台并引入 Work 白板画布，PPT 演示形成从方向选择、图片优先评审到导出的完整工作流，Write 支持办公文档预览、讨论与本地知识检索，探索型子代理升级更名为 Fast Context；同时侧栏会话改为分页渐进加载，运行时在提示词缓存、会话压缩、用量统计与恢复能力上做了大量稳定性加固。

### 工作台与白板

- Code、Design、Work 三种模式统一为同一个工作台入口，Work 白板成为新的画布承载面，支持会话管理、导航与标题显示。
- 新增 CodeCanvas 设计面，可在白板面板中查看设计文档；画布设计系统集成与放置逻辑增强，视口同步与图片生成进度实时展示。
- 设计工具改为两阶段回执（two-phase receipts），模型能看到画布操作的真实结果；顶层文本别名规范化、无效操作日志持久化、画布引用按意图缩放。
- 白板存储目录由 `.kun-write/whiteboards` 迁移到 `.kun-whiteboards`。
- 修复嵌入式白板工作流、会话列表与画布交付、任务身份保持、首轮任务意图保持、每轮 Code / Design 表面选择与白板标题同步等一批问题。

### PPT 演示工作流

- 新增 ppt_agent 本地工具（PPT 导出、指南读取）与对应 Lab 设置，Work 演示流程恢复并整体稳定。
- 支持视觉方向选择与图片优先（image-first）评审工作流，并增加几何质量门禁与本地化文案回退。
- pptx 胶片条（filmstrip）与全屏预览；Office 文件可在内置浏览器中渲染并实时预览。
- PPT 代理使用独立的设计权限隔离；恢复会话中的 PPT 代理历史卡片。

### Write 写作与本地知识

- 办公文档本地索引，Write 工作区提供无向量的检索（vectorless retrieval）。
- 支持办公文档预览与讨论，新增文档引用功能。
- Write 助手面板与编辑器分组增强；修复排队中的用户输入恢复与重复的选区 AI composer。

### Fast Context（原 explore_agent）

- 探索型子代理 `explore_agent` 更名为 Fast Context，保留只读调查定位，仍是仓库调查的第一步。
- 新增 Fast Context 证据卡片与详情组件，调查结果以证据形式在会话中展示，支持批量并行调查。

### 会话列表与加载性能

- 侧栏改为缓存优先启动、按工作区分页渐进加载，项目线程分批展开，未读与运行中的线程优先展示。
- `/v1/threads` 支持 keyset 分页与精简投影，大幅降低大工作区的列表开销。
- 修复分页时间线中当前轮用户消息的锚定，避免滚动丢失正在进行的对话。

### Persona 人设

- 内置 Code 代理人设预设目录；人设编辑器支持可搜索的 lucide 图标选择器。
- Composer 增加人设选择器，按轮次发送所选人设；Kun 侧以缓存安全的方式注入每轮 persona，不破坏提示词缓存。

### 子代理与委托

- 支持批量并行的 Fast Context 调查；中断的子代理运行可以恢复，子代理管理支持用户主动停止。
- 代理卡片默认折叠，聚焦模式隐藏子代理 logo，过期运行状态回放时卡片保持终态。
- 修复超大子结果外化、移除累计子代理运行次数上限、失败子代理保留已累计用量。

### 运行时、缓存与用量

- 保持热轮提示词缓存命中；会话压缩移出活动轮路径；累计工具结果规范化保证缓存稳定。
- 用量事件支持压缩与流式查询；新增平均 TTFT、每秒 token 数等指标；重开会话可恢复缓存命中指标。
- 运行时看门狗支持冷启动恢复；重启后自动恢复中断的任务；只替换当前 `kun serve` 进程，繁忙线程与长任务更稳定。
- Git checkpoint 存储增加硬保留上限与磁盘配额，防止存储无限膨胀，且默认关闭。
- 模型目录加载、用量记录加载与 UTF-8 处理增强；Kimi K3 系列模型不再发送固定采样参数。

### Agent Graph 与 Plan

- Graph 安全分类规划宿主失败、脱敏不完整的工具参数、恢复被包裹的规划参数、要求具备命令执行能力的验证 scope、保留不相交的工作区变更，并防止监督投递活锁。
- 运行时错误按时间线顺序展示；外部化回放产物可访问。
- Plan 内联构建卡片重新设计；plan worktree 准入与恢复机制增强，plan-build 准入绑定持久化并可修复。

### 其他改进

- Telegram 每连接代理配置；Linux 支持系统标题栏；UI 插件字符尺寸控制。
- 完成通知与未读管理；排队消息支持暂停投递状态。
- 空会话欢迎标题可自定义；composer 用量底栏响应式重设计。
- 自定义 Provider 探针复用已存凭据；Windows 修复陈旧迁移日志的恢复；macOS Dock 图标保持可见。
- 修复一轮对话内助手最终回复重复、中文工具失败后的进度续写恢复等问题。

### 升级说明

- 从 v0.2.37 升级无需手动迁移会话、工作区或 Provider 配置。
- Work 白板存储目录迁移到 `.kun-whiteboards`：新版本不会读取旧的 `.kun-write/whiteboards` 数据，如需保留历史白板请手动迁移目录。
- `explore_agent` 更名为 Fast Context：能力定位不变，仍按原有 Lab 开关生效。
- Git checkpoints 默认改为关闭，可在设置中重新开启。
